Ejercicios de Arreglos Bidimensionales

Arreglo de 2 filas por 3 columnas

a) Declarar y crear el arreglo t

let t = [
    [0, 0, 0],
    [0, 0, 0]
];

b) ¿Cuántas filas tiene t?

let filas = t.length; // 2 filas

c) ¿Cuántas columnas tiene t?

let columnas = t[0].length; // 3 columnas

d) ¿Cuántos elementos tiene t?

let elementos = t.length * t[0].length; // 6 elementos

e) Nombres de los elementos de la fila 1

t[1][0], t[1][1], t[1][2]

f) Nombres de los elementos de la tercera columna

t[0][2], t[1][2]

g) Establecer el elemento de la fila 1 y columna 2 en cero

t[1][2] = 0;

h) Inicializar cada elemento de t en cero


t[0][0] = 0;
t[0][1] = 0;
t[0][2] = 0;
t[1][0] = 0;
t[1][1] = 0;
t[1][2] = 0;

i) Inicializar cada elemento usando for anidados


for (let i = 0; i < 2; i++) {
    for (let j = 0; j < 3; j++) {
        t[i][j] = 0;
    }
}

j) Determinar e imprimir el valor más pequeño


let menor = t[0][0];

for (let i = 0; i < 2; i++) {
    for (let j = 0; j < 3; j++) {
        if (t[i][j] < menor) {
            menor = t[i][j];
        }
    }
}

document.write("Valor menor: " + menor);

k) Mostrar los elementos de la primera fila sin repetición


document.write(t[0][0] + " ");
document.write(t[0][1] + " ");
document.write(t[0][2]);

l) Imprimir el arreglo en formato tabular


// Encabezados de columnas
document.write("   0   1   2
");

for (let i = 0; i < 2; i++) {
    document.write(i + " ");

    for (let j = 0; j < 3; j++) {
        document.write(t[i][j] + "   ");
    }

    document.write("
");
}
